# Como colocar o Desafio Keto no ar

Nenhum passo aqui exige digitar comandos — tudo é feito clicando, pelo navegador.
São 4 etapas: banco de dados, chave de IA, subir o código, publicar.

---

## 1. Criar o banco de dados (Supabase — gratuito)

1. Acesse **supabase.com** e crie uma conta gratuita.
2. Clique em **New Project**. Dê um nome (ex: "desafio-keto") e uma senha (guarde
   essa senha, mas ela não será usada nos próximos passos).
3. Espere o projeto ser criado (leva 1-2 minutos).
4. No menu lateral, clique em **SQL Editor** → **New query**.
5. Cole exatamente isto e clique em **Run**:

```sql
create table meals (
  id bigint generated by default as identity primary key,
  student_name text not null,
  date date not null,
  slot text not null,
  score int not null,
  feedback text,
  created_at timestamptz default now(),
  unique (student_name, date, slot)
);
```

6. No menu lateral, clique em **Project Settings** (ícone de engrenagem) → **API**.
7. Guarde estes dois valores, você vai precisar deles daqui a pouco:
   - **Project URL**
   - **service_role key** (clique em "Reveal" para ver — é diferente da "anon" key)

---

## 2. Criar a chave da IA (Anthropic Console)

1. Acesse **console.anthropic.com** e crie uma conta (ou entre na sua).
2. Adicione algum crédito (a análise de cada foto custa uma fração de centavo).
3. Vá em **API Keys** → **Create Key**. Copie a chave gerada (começa com `sk-ant-`).
   Guarde-a — ela só aparece uma vez.

---

## 3. Subir o código para o GitHub

1. Acesse **github.com** e crie uma conta gratuita, se ainda não tiver.
2. Clique em **New repository**. Nomeie como `desafio-keto` e clique em **Create repository**.
3. Na página do repositório vazio, clique em **uploading an existing file**.
4. Arraste TODOS os arquivos e pastas deste projeto (a pasta `app`, a pasta `public`,
   a pasta `lib`, o `package.json`, etc.) para essa área.
5. Clique em **Commit changes**.

---

## 4. Publicar (Vercel — gratuito)

1. Acesse **vercel.com** e crie uma conta usando "Continue with GitHub".
2. Clique em **Add New** → **Project**.
3. Selecione o repositório `desafio-keto` que você acabou de criar.
4. Antes de clicar em Deploy, abra **Environment Variables** e adicione as três:

   | Nome                          | Valor                                  |
   |-------------------------------|-----------------------------------------|
   | `ANTHROPIC_API_KEY`           | a chave que começa com `sk-ant-`        |
   | `NEXT_PUBLIC_SUPABASE_URL`    | o Project URL do Supabase               |
   | `SUPABASE_SERVICE_ROLE_KEY`   | a service_role key do Supabase          |

5. Clique em **Deploy**. Em cerca de 1 minuto, a Vercel te dá um link
   (algo como `desafio-keto.vercel.app`) — esse é o app no ar.

---

## Dando o app para os alunos

Envie o link da Vercel para os alunos. No celular, ao abrir o link:

- **Android (Chrome)**: menu (⋮) → "Adicionar à tela inicial"
- **iPhone (Safari)**: botão de compartilhar → "Adicionar à Tela de Início"

Assim o app fica com ícone próprio, como um aplicativo normal.

---

## Se algo der errado

- Tela em branco ou erro ao publicar → confira se as 3 variáveis de ambiente
  foram coladas certinhas (sem espaços extras).
- "Não foi possível avaliar a foto" → verifique se ainda há crédito na conta
  da Anthropic.
- Qualquer erro específico, me mande o print que eu te ajudo a resolver.
